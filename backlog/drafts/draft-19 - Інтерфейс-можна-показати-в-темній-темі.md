## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Багато хто тримає Windows у темній темі, а revisor завжди світлий: вікно різко вирізняється серед інших, а слабозорим людям і тим, хто працює вночі, світлий фон заважає. Темна тема має з'явитися без втрат для скрінрідера, бо revisor робимо насамперед для користувачів NVDA.

Що вже відомо (дослідження й жива перевірка 2026-11-07):
- wxDragon 0.9.24 збирає wxWidgets 3.3.4, який має темну тему для Windows і вміє перемикати світлу й темну тему під час роботи (з 3.3.3).
- Microsoft офіційно не підтримує темну тему для класичних Win32-застосунків, тож wxWidgets спирається на недокументовані функції Windows; майбутнє оновлення Windows теоретично може щось зламати.
- У темній темі wxWidgets сам малює прапорці; раніше через це NVDA озвучував їх як кнопки (виправлено у 3.3.2).
- Жива перевірка з NVDA (тему ввімкнено змінною середовища `wx_msw_dark_mode=2`, без змін у коді): релізний прохід `tools/nvda/release_pass.py` дав «all heard»; прапорці в налаштуваннях і фільтрах озвучуються як «прапорець, позначено / не позначено»; виділений рядок списку видно й без фокусу; меню, заголовки колонок, поля, рядок стану й «Налаштування» темні.
- Не перевірено: висока контрастність Windows, вікна повідомлень, вікно профілю й вибір теки на вигляд, перемикання теми без перезапуску.

Етап: розширення 0.x.

Ще не вирішено:
- чи тема лише йде за Windows, чи користувач вибирає «Як у Windows / Світла / Темна» в налаштуваннях;
- чи змінюється тема одразу, чи після перезапуску;
- що робити, коли в Windows увімкнено високу контрастність.

Чернетка: вимоги ще обговорюються.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Коли Windows у темній темі, revisor показує всі свої вікна темними: головне вікно, меню, діалоги, вікна повідомлень і рядок стану.
- [ ] #2 У темній темі NVDA озвучує всі елементи так само, як у світлій: роль, назву, стан прапорця й клавішу доступу.
- [ ] #3 У темній темі виділений рядок списку видно і з фокусом, і без нього.
- [ ] #4 У режимі високої контрастності Windows revisor не ламає кольори високої контрастності.
- [ ] #5 Релізний прохід з NVDA проходить («all heard») і у світлій, і в темній темі.
<!-- AC:END -->
