## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Список різниці завжди показує шість колонок у незмінному порядку, а їхні ширини зашито в коді (`COLUMN_WIDTHS` у `crates/revisor/src/main_window.rs`). NVDA читає кожен рядок усіма колонками. Якщо переглядаєш сотні змін, найдовша колонка «Тека» (повний шлях) і «Дата зміни» здебільшого лише заважають. Схоже налаштування для дерева вже є: «Вузли дерева».

Пропозиція: налаштування «Колонки списку різниці» визначає, які колонки показувати і в якому порядку; за замовчуванням це всі шість у нинішньому порядку. Схожі інструменти так роблять: WinMerge має вікно Display Columns (показати, сховати, переставити, повернути типові), а для NVDA існує додаток Columns Review, бо читати всі колонки підряд незручно.

Метрика корисності: без «Тека» й «Дата зміни» рядок коротшає приблизно на 50–60 % символів (оцінка, її треба виміряти); для різниці з 300 змін це сотні слів NVDA.

Вкладка налаштувань: «Різниця» (TASK-44).

Відкрите питання: чи запам'ятовувати ширини колонок, без окремого налаштування.

Походження: дослідження налаштувань 2026-11-13.
