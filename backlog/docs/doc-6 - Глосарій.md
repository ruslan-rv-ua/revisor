# Глосарій revisor

> Терміни, щоб інтерфейс, переклади, код і документація вживали одні й ті самі слова. Українські терміни погоджено в обговоренні брифу. Англійські відповідники — пропозиція, уточнюємо їх по ходу.

## Програма

- **Загальні налаштування** / Settings — налаштування програми, що не належать жодному профілю: наприклад, профіль, відкритий минулого разу, фокус після знімка й фокус після порівняння (ADR-0007).
- **Фонова робота** / Background job — знімок, стискання бази чи порівняння, яке йде на власному потоці, поки головним вікном можна користуватися: з прогресом у головному вікні, кнопкою «Скасувати» й результатом, про який revisor каже, коли робота закінчилася. Одночасно йде не більше ніж одна робота кожного виду (ADR-0011).

## Керування

- **Гаряча клавіша** / Keyboard shortcut — сполучення клавіш (Ctrl+…, F-клавіша), яке запускає часту команду з будь-якого місця головного вікна; її видно в меню поруч із командою. У Microsoft — «сполучення клавіш» і «keyboard shortcut» (TASK-25). Усі гарячі клавіші — у документі «Клавіатура й меню».
- **Клавіша доступу** / Access key — підкреслена латинська літера в назві меню, пункту меню чи контрола: разом з Alt вона відкриває меню, вибирає пункт чи переводить фокус на контрол. В українському інтерфейсі літера стоїть у дужках після назви («Файл (F)»).
- **Рядок стану** / Status bar — смуга внизу головного вікна, де з'являються повідомлення, які revisor каже без перенесення фокуса (наприклад, чому команда зараз недоступна). NVDA читає кожне повідомлення сам, а NVDA+End повторює останнє.

## Профілі

- **Профіль** / Profile — іменований набір тек із винятками й налаштуваннями, у якого є власний перелік знімків.
- **Відкритий профіль** / Open profile — профіль, вибраний у головному вікні; перелік знімків показує саме його знімки.
- **Виняток** / Exclusion — шаблон шляху чи імені. Файли й теки, що йому відповідають, не потрапляють у знімок.
- **Типовий список винятків** / Default exclusions — винятки, які отримує новий профіль (тимчасові файли, кеші, кошик тощо). Їх можна редагувати як звичайні винятки.

## Знімки

- **Знімок** / Snapshot — зафіксований стан файлів і тек профілю на певний момент.
- **Назва знімка** / Snapshot name — дата й час, коли знімок запустили, у регіональному форматі користувача (коротка дата й час із секундами).
- **Перелік знімків** / Snapshot list — знімки профілю в порядку створення: від найстарішого (угорі) до найновішого (внизу).
- **Поточний знімок** / Current snapshot — знімок, на якому стоїть фокус у переліку.
- **Попередній знімок** / Previous snapshot — знімок, що стоїть у переліку перед поточним (зроблений раніше).
- **Коментар знімка** / Snapshot comment — необов'язковий текст до знімка, наприклад «перед встановленням X».
- **Хеш вмісту** / Content hash — контрольна сума вмісту файлу; опція профілю (етап 0.x).
- **Джерело** / Source — звідки беруться записи знімка: поки лише файлова система, згодом, можливо, реєстр (ADR-0003).
- **Запис** / Entry — вузол дерева знімка: шлях, вид (контейнер чи елемент) і атрибути.
- **Версію не прочитано** / Version not read — позначка exe чи dll, версії якого знімок не прочитав (немає доступу до вмісту, файл заблокувала інша програма чи він лежить лише в хмарі). Зміною ця позначка не є, а решта даних файлу порівнюється як завжди.
- **Відсутня тека** / Missing folder — тека профілю, якої під час знімка немає на диску, хоч її том на місці. Порівняння вважає її порожньою, тож її колишній вміст стає видаленим чи доданим.

## Порівняння й різниця

- **Порівняння** / Comparison — зіставлення двох знімків одного профілю.
- **Швидке порівняння** / Quick compare — поточний знімок із попереднім.
- **Порівняння на вибір** / Compare with — поточний знімок з іншим знімком того самого профілю, який вибрав користувач.
- **Знімок + порівняння** / Snapshot and compare — команда, яка робить новий знімок і одразу порівнює його з попереднім, тобто зі знімком, що був найновішим до нього, хоч де стоїть фокус.
- **Раніший і пізніший знімок** / Earlier and later snapshot — два знімки порівняння за порядком створення, хоч який із них поточний; різниця йде від ранішого до пізнішого.
- **Різниця** / Difference — результат порівняння: перелік змін, а поруч із ними — недоступні записи.
- **Зміна** / Change — елемент різниці одного з типів:
  - **додано** / Added;
  - **видалено** / Deleted;
  - **змінено** / Modified; зокрема **замінено** / Replaced — за тим самим шляхом тепер інший файл чи тека (інший ідентифікатор файлу NTFS);
  - **перейменовано або переміщено** / Renamed or moved (етап 0.x).
- **Недоступний запис** / Inaccessible entry — запис, недоступний хоча б в одному з двох знімків. Різниця показує його серед змін із типом «недоступно» / Inaccessible, але зміною він не вважається.
- **Підсумок** / Summary — кількість змін кожного типу й недоступних записів та зміна сумарного розміру.
- **Подробиці «було → стало»** / Details (before → after) — усі дані вибраної зміни чи недоступного запису до й після.
